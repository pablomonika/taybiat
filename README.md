# نظام الطيبات — النسخة المعاد بناؤها

إعادة بناء تحريرية وتصميمية كاملة لكتاب **«نظام الطيبات — الدليل الشامل للغذاء الصحّي الطبيعي»**
عن رؤى الدكتور **ضياء العوضي** (رحمه الله، 1980–2026)، استناداً إلى الملف الأصلي
`altayebaat-2026-edition2.pdf`.

## الناتج النهائي

- **`نظام-الطيبات-النسخة-المعاد-بناؤها.pdf`** — 104 صفحات بمقاس **A5** للطباعة، يتضمن:
  - غلافاً أمامياً وخلفيين جديدين، صفحة عنوان، وصفحة حقوق نشر، وفهرساً مرقّماً.
  - سبعة أبواب بصفحات افتتاحية، وكل فصل مبني على: أهداف ← شرح ← صناديق (مفتاح/تنبيه/تطبيق) ← خلاصة.
  - قوائم المسموحات (89 صنفاً/18 فئة) والممنوعات (81+ صنفاً/16 فئة) بجداول نظيفة ووسوم تكرار لونية.
  - 25 بديلاً، وخطة تطبيق أسبوعية، و25 نظرية، وتطبيق النظام على خمسة أمراض، والخاتمة والمصادر.
  - شارات تنقل (Bookmarks) وبيانات تعريفية للملف، ترويسات وأرقام صفحات متسقة.

## كيف بُني الكتاب

الناتج يُولَّد بـ **PyMuPDF Story** (HTML/CSS مع تشكيل عربي حقيقي) وخطوط عربية مدمجة
(Noto Naskh للنص، Noto Kufi للعناوين، Amiri للآيات).

```bash
pip install --break-system-packages pymupdf fonttools pillow brotli

cd work
python3 build.py          # يُنتج work/نظام-الطيبات-النسخة-الجديدة.pdf
```

الكود المصدري في `work/`:

| الملف | الدور |
|------|------|
| `build.py` | تجميع المقاطع، الفهرس بأرقام الصفحات، الترويسات، الشارات، البيانات الوصفية |
| `book/css.py` | نظام التصميم (الألوان، الخطوط، الجداول، الصناديق، الترويسة) |
| `book/data.py` | البيانات: المسموحات، الممنوعات، البدائل، الخطة الأسبوعية، النظريات الـ25 |
| `book/part1..7.py` | نصوص الأبواب السبعة (معاد صياغتها بالكامل) |
| `book/front.py` / `book/back.py` | التمهيد والسيرة / الخاتمة والمصادر |
| `book/cover.py` | رسم الغلاف الأمامي والخلفي وصفحتي العنوان وحقوق النشر |
| `book/helpers.py` | دوال بناء HTML المشتركة |
| `book/parts.py` | تعريف الأبواب وصفحاتها الافتتاحية |

## ملاحظة

موضع حذف الجملة (البند 6 من التعليمات) وصل فارغاً (قالب `[ضع هنا الجملة…]` دون نص)،
فبُني الكتاب كاملاً دون حذف أي محتوى علمي (مع دمج التكرارات الطبيعية أثناء إعادة التنظيم).
المحتوى يعرض رؤية الدكتور لأغراض تثقيفية، وليس بديلاً عن الاستشارة الطبية.
